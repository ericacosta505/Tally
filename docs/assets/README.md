# README assets

These files are checked into the repository so GitHub can render the project overview without third-party image hosting.

| Asset                | Origin                                                                                                                          |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| `tally-cover.svg`    | Original, editable vector cover using the app’s tally mark, ink, and chartreuse palette. No external fonts, scripts, or images. |
| `tally-overview.png` | Unedited full-page capture of the local React application, Overview view, using sample demo data.                               |
| `tally-forecast.png` | Unedited full-page capture of the local React application, Forecast view, with a 25% future variable-spending reduction.        |

Screenshots captured September 10, 2026. Figures belong to the sample workspace, not a real account. Sample data is generated relative to the current date, so fresh demos may differ from these images.

To refresh the screenshots, start the frontend, open the demo, and capture the relevant views. Keep the visible demo label and replace the assets at their existing paths. Update the scenario amount in the root README if the forecast capture changes.
